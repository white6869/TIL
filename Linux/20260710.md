## 📁 파일 & 디렉터리 관리

### `mv` — 파일/디렉터리 이동 및 이름 변경
```bash
mv [옵션] 파일명 파일명
```
| 옵션 | 설명 |
|------|------|
| `-i` | 덮어쓰기 확인 |
| `-f` | 강제 덮어쓰기 |
| `-v` | 이동 과정 출력 |
| `-n` | 대상 파일이 이미 존재하면 이동하지 않음 |

### `rm` — 파일/디렉터리 삭제
```bash
rm [옵션] 파일이름
```
| 옵션 | 설명 |
|------|------|
| `-i` | 삭제 여부 확인 |
| `-f` | 확인 없이 모두 삭제 |
| `-r` | 하위 디렉터리 내용까지 모두 삭제 (디렉터리 완전 삭제 시 유용) |

### `touch` — 빈 파일 생성 / 시간 정보 변경
```bash
touch [옵션] 파일이름
```
| 옵션 | 설명 |
|------|------|
| `-c` | 지정한 파일이 존재하지 않아도 새로 생성하지 않음 |
| `-r file` | 최종 갱신일을 file 날짜에 맞춤 |
| `-t time` | 최종 갱신일을 time으로 변경 |

### `rmdir` — 빈 디렉터리 삭제
```bash
rmdir [옵션] 디렉터리명
```
| 옵션 | 설명 |
|------|------|
| `-p` | 상위 디렉터리까지 함께 삭제 (비어 있어야 가능) |

### 📍 경로 이동
- **`pwd`** : 현재 작업 중인 디렉터리의 전체 경로 출력
- **`cd`** : 홈 디렉터리로 이동
- **`cd 디렉터리명`** : 해당 디렉터리로 이동 (현재 작업 디렉터리 내부에 없으면 불가)

## 🔍 검색 & 위치 확인

### `which` — 실행 파일 경로 출력
```bash
which [옵션] 명령어
```
| 옵션 | 설명 |
|------|------|
| `-a` | 경로에 같은 이름의 파일이 여러 개면 모두 출력 |

### `whereis` — 실행/소스/매뉴얼 파일 위치 검색
```bash
whereis [옵션] 명령어
```
| 옵션 | 설명 |
|------|------|
| `-b` | 실행 파일만 검색 |
| `-m` | 매뉴얼 파일만 검색 |
| `-s` | 소스 파일만 검색 |

### `grep` — 문자열 검색
```bash
grep [옵션] 패턴 파일
```
| 옵션 | 설명 |
|------|------|
| `-v` | 지정한 패턴을 포함하는 줄을 제외하고 표시 |
| `-n` | 줄 번호를 함께 표시 |
| `-l` | 지정한 문자열을 포함한 파일명 표시 |
| `-i` | 대소문자 구분 없이 검색 |
| `-r` | 서브 디렉터리까지 재귀적으로 검색 |
| `-s` | 에러 메시지를 표시하지 않음 |

## 🖥️ 시스템 정보

### `df` — 디스크 용량 표시
> 디바이스 · 디스크 용량 · 사용한 용량 · 여유 용량 · 사용률 · 마운트 정보 순으로 표시

### `du` — 파일/디렉터리의 디스크 사용량 확인

### `last` — 사용자 로그인/로그아웃 기록 확인
> 사용자명 · 터미널 · 호스트명 · 시각과 상태 순으로 표시

| 옵션 | 설명 |
|------|------|
| `-n` | n행 분량의 로그인 이력 표시 |
| `-x` | 런레벨 변경 표시 (시스템 상태를 나타내는 값) |

### `uptime` — 시스템 가동 시간 & 부하 확인
| 옵션 | 설명 |
|------|------|
| `-p` | 가동 시간만 표시 |
| `-s` | 시스템 시작 시각만 표시 |

### `uname` — 시스템 정보 표시
| 옵션 | 설명 |
|------|------|
| `-a` | 모든 정보 표시 (시스템명·호스트명·OS 릴리스 번호·커널 컴파일 정보·머신 타입·프로세서 타입·하드웨어 플랫폼·OS 순) |
| `-n` | 호스트명 표시 |
| `-r` | OS 릴리스 번호 표시 |
| `-v` | 커널 컴파일 정보 표시 |
| `-m` | 머신 타입 표시 |
| `-p` | 프로세서 타입 표시 |

## 📝 텍스트 처리

### `uniq` — 연속된 중복 줄 제거
| 옵션 | 설명 |
|------|------|
| `-u` | 중복되지 않은 줄만 출력 |
| `-d` | 중복된 줄만 출력 |
| `-c` | 중복된 줄 수를 각 줄 옆에 표시 |

### `diff` — 파일/디렉터리 비교
```bash
diff [옵션] 파일1 파일2
```
| 옵션 | 설명 |
|------|------|
| `-i` | 대소문자 차이 무시 |
| `-r` | 서브 디렉터리도 비교 |
| `-s` | 두 파일 내용이 같으면 같다는 정보 표시 |
| `-b` | 줄 끝 공백 문자 차이 무시 |
| `-w` | 모든 공백 문자 차이 무시 |
| `-B` | 빈 줄 개수 차이 무시 |
| `-q` | 파일 내용 일치 여부만 표시 |

## 🔐 권한 관리

### `chown` — 파일/디렉터리의 소유자와 그룹 변경

### `chmod` — 파일/디렉터리의 접근 권한 변경
> 읽기(r) · 쓰기(w) · 실행(x) 권한을 사용자별로 설정 가능

| 권한 | 값 |
|------|-----|
| `r` (읽기) | 4 |
| `w` (쓰기) | 2 |
| `x` (실행) | 1 |

- `rwx` = **7** (8진수)로 표시 가능

## 🌐 네트워크

### `ping [옵션] 상대호스트`
다른 호스트와의 연결 상태를 확인

### `ssh` — 원격 서버 접속
```bash
ssh [옵션] 사용자명@호스트명
```
> 암호화된 방식으로 안전하게 접속 (기본 22번 포트 사용). `exit` 또는 `logout`으로 접속 종료

| 옵션 | 설명 |
|------|------|
| `-p` | 포트 번호 지정 |
| `-i` | 개인 키 지정 |
| `-v` | 상세 정보 출력 |

### `ip addr`
IP 주소를 확인하거나 설정 (재부팅 시 설정 초기화 — **임시** 설정)

### `nmcli`
NetworkManager를 CLI에서 관리 — 네트워크 연결 상태 확인, IP 설정, DNS 변경, 인터페이스 활성화/비활성화 등 수행
> ⚡ `ip addr`와 달리 **영구적으로** 네트워크 설정 변경

## ⚙️ 서비스 & 패키지 관리

### `systemctl` — systemd 기반 서비스/시스템 상태 관리
| 명령 | 설명 |
|------|------|
| `start` | 서비스 시작 |
| `stop` | 서비스 중지 |
| `restart` | 서비스 재시작 |
| `reload` | 설정만 다시 읽기 |
| `status` | 서비스 상태 확인 |
| `enable` | 부팅 시 자동 시작 |
| `disable` | 부팅 시 자동 시작 해제 |

### `dnf` — 패키지 관리
```bash
dnf [옵션] 명령 패키지명
```
| 명령 | 설명 |
|------|------|
| `install` | 패키지 설치 |
| `update` | 패키지 업데이트 (패키지명 미지정 시 설치 가능한 모든 패키지 업데이트) |
| `check-update` | 업데이트 가능한 패키지 확인 |
| `remove` | 패키지 제거 |

### `mkfs [옵션] 장치명`
디스크나 파티션에 파일 시스템을 포맷

## 🧩 기타 명령어

- **`clear`** : 터미널에 출력된 내용 지우기
