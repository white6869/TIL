# 📂 ls 명령어

`ls`는 **파일 및 디렉터리 목록을 출력하는 명령어**입니다.

```bash
ls [옵션]
```

## ⭐ 주요 옵션

| 옵션                       | 설명                                |
| ------------------------ | --------------------------------- |
| `-a`, `--all`            | 숨김 파일(`.`으로 시작하는 파일)까지 모두 출력      |
| `-A`, `--almost-all`     | 숨김 파일은 출력하지만 `.`과 `..`은 제외        |
| `-b`, `--escape`         | 특수문자를 `\n`, `\t` 등의 C 언어 형식으로 출력  |
| `-B`, `--ignore-backups` | `~`로 끝나는 백업 파일 제외                 |
| `-c`                     | 상태 변경 시간을 기준으로 정렬 또는 표시           |
| `-C`                     | 여러 열(Column) 형태로 출력               |
| `-d`, `--directory`      | 디렉터리 내부가 아닌 디렉터리 자체 정보 출력         |
| `-D`, `--dired`          | Emacs dired 모드용 출력                |
| `-f`                     | 정렬하지 않고 빠르게 출력                    |
| `-F`                     | 파일 종류를 나타내는 기호(`*`, `/` 등) 추가     |
| `-u`                     | 접근 시간(Access Time) 기준으로 정렬 또는 표시  |
| `-U`                     | 디렉터리 저장 순서대로 출력(정렬 안 함)           |
| `-v`                     | 숫자를 자연스럽게 정렬 (`file2` → `file10`) |
| `-w COLS`                | 출력 폭을 지정 (`0`이면 제한 없음)            |
| `-x`                     | 세로가 아닌 가로 방향으로 출력                 |
| `-X`                     | 확장자 기준으로 정렬                       |
| `-Z`                     | SELinux 보안 컨텍스트 표시                |
| `-1`                     | 한 줄에 파일 하나씩 출력                    |
| `--block-size=SIZE`      | 파일 크기 단위 지정                       |
| `--version`              | 버전 정보 출력                          |

### 💡 자주 사용하는 예시

```bash
ls -al
```

> 숨김 파일을 포함하여 자세한 정보를 출력

```bash
ls -lh
```

> 사람이 읽기 쉬운 단위(KB, MB, GB)로 출력

```bash
ls -alh
```

> 실무에서 가장 많이 사용하는 조합

# 📁 mkdir 명령어

새로운 디렉터리를 생성한다.

```bash
mkdir [옵션] 디렉터리명
```

### 💡 예시

```bash
mkdir project
```

`project` 디렉터리를 생성한다.

# 📄 cat 명령어

파일 내용을 출력하거나 여러 파일을 연결할 때 사용한다.

```bash
cat [옵션] 파일명
```

## ⭐ 주요 사용 예시

### 파일 내용 출력

```bash
cat file1
```

### 여러 파일 이어서 출력

```bash
cat file1 file2
```

### 여러 파일을 하나의 파일로 저장

```bash
cat file1 file2 > file3
```

→ `file1`과 `file2`의 내용을 합쳐 `file3`에 저장

## ⭐ 주요 옵션

| 옵션   | 설명                      |
| ---- | ----------------------- |
| `-n` | 모든 줄에 번호 출력             |
| `-b` | 내용이 있는 줄만 번호 출력         |
| `-A` | 숨겨진 문자까지 모두 표시 (`-vET`) |

# 📋 cp 명령어

파일이나 디렉터리를 복사한다.

```bash
cp [옵션] 원본 대상
```

### 💡 예시

```bash
cp file1 file2
```

→ `file1`을 `file2`라는 이름으로 복사

## ⭐ 주요 옵션

| 옵션   | 설명                          |
| ---- | --------------------------- |
| `-r` | 디렉터리까지 재귀적으로 복사             |
| `-i` | 덮어쓰기 전 확인                   |
| `-f` | 확인 없이 강제로 덮어쓰기              |
| `-v` | 복사 과정을 출력                   |
| `-u` | 원본이 더 최신인 경우에만 복사           |
| `-p` | 권한, 소유자, 시간 정보를 유지          |
| `-a` | 원본의 속성을 최대한 유지하여 복사(백업에 유용) |

### 💡 자주 사용하는 예시

```bash
cp file1 backup.txt
```

```bash
cp -r dir1 dir2
```

```bash
cp -av config backup/
```

→ 백업 작업에서 자주 사용

# 💡 옵션 작성 방법

Linux 옵션은 **짧은 옵션**과 **긴 옵션**으로 나뉜다.

## 짧은 옵션

```bash
ls -a
```

## 긴 옵션

```bash
ls --all
```

---

## 여러 옵션 함께 사용

### 붙여 쓰기

```bash
ls -alh
```

### 띄어 쓰기

```bash
ls -a -l -h
```

두 명령은 **동일한 의미**이다.

---

## ⚠️ 주의사항

정렬 옵션처럼 **같은 기능을 수행하는 옵션을 함께 사용하면 마지막 옵션이 적용되는 경우가 많다.**

예시

```bash
ls -t -X
```

→ `-X`(확장자 정렬)이 적용된다.

# 📌 핵심 정리

* 📂 `ls` : 파일 및 디렉터리 목록 확인
* 📁 `mkdir` : 새 디렉터리 생성
* 📄 `cat` : 파일 내용 확인 및 파일 연결
* 📋 `cp` : 파일 및 디렉터리 복사
* 💡 짧은 옵션은 `-alh`처럼 함께 사용할 수 있으며, 긴 옵션은 `--all`과 같이 작성한다.
