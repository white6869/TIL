## 1. Stack (스택)

### 💡 핵심 개념

> **LIFO (Last In First Out)** — 가장 나중에 들어온 것이 가장 먼저 나간다

```
push 순서         pop 순서
                  
  [ C ] ← top      [ C ] → 꺼냄
  [ B ]             [ B ] → 꺼냄
  [ A ]             [ A ] → 꺼냄
```

<br>

### 📌 선언

```java
import java.util.Stack;

Stack<Integer> stack = new Stack<>();
Stack<String>  stack = new Stack<>();
```

<br>

### 🔧 주요 메소드

| 메소드 | 역할 | 예시 |
|--------|------|------|
| `push(val)` | top에 추가 | `push(3)` → `[1, 2, 3]` |
| `pop()` | top 제거 + 반환 | `[1, 2, 3]` → `3` 반환 후 제거 |
| `peek()` | top 확인 (삭제 X) | `[1, 2, 3]` → `3` 유지 |
| `empty()` | 비었는지 확인 | `true` / `false` |
| `search(val)` | top 기준 위치 (1-based) | `search(10)` → `3` |

<br>

### 💻 동작 예시

```java
Stack<Integer> stack = new Stack<>();

stack.push(1);  // [1]
stack.push(2);  // [1, 2]
stack.push(3);  // [1, 2, 3]

System.out.println(stack.pop());   // 3  ← 제거됨
System.out.println(stack.peek());  // 2  ← 유지됨

// search() 예시
// [10, 20, 30] 상태일 때
stack.search(30); // → 1  (top에서 1번째)
stack.search(10); // → 3  (top에서 3번째)
```

<br>

### ✅ 대표 문제 유형

- **괄호 유효성 검사** — `(()())` 올바른 괄호인지 확인
- **폭발 문자열 / 연속 문자 제거** — 연속된 같은 문자 제거
- **문자열 뒤집기** — reverse 구현

## 2. Integer.parseInt() vs Integer.valueOf()

> 둘 다 `String → 숫자` 변환이지만, **반환 타입**이 다르다

<br>

### 🔵 Integer.parseInt() — `int` (기본형) 반환

```java
int num = Integer.parseInt("123");

int a = Integer.parseInt("10");
int b = Integer.parseInt("20");
System.out.println(a + b); // 30
```

- 반환 타입: **`int`**
- 계산에 바로 사용 가능
- 가볍고 빠름

<br>

### 🟣 Integer.valueOf() — `Integer` (객체) 반환

```java
Integer num = Integer.valueOf("123");

Integer a = Integer.valueOf("10");
Integer b = Integer.valueOf("20");
System.out.println(a + b); // 30 (자동 언박싱)
```

- 반환 타입: **`Integer`**
- 컬렉션(ArrayList, Stack 등)에 담을 때 사용
- 내부 캐싱으로 성능 최적화 가능

<br>

### ⚖️ 비교 정리

| 구분 | `parseInt()` | `valueOf()` |
|------|:---:|:---:|
| 반환 타입 | `int` (기본형) | `Integer` (객체) |
| 속도 | ⚡ 더 빠름 | 약간 무거움 |
| 사용 용도 | 계산 | 컬렉션 / 객체 처리 |

<br>

### 🤔 언제 쓸까?

```java
// ✅ 계산할 때 → parseInt
int sum = Integer.parseInt("100") + 50;

// ✅ 컬렉션에 넣을 때 → valueOf
ArrayList<Integer> list = new ArrayList<>();
list.add(Integer.valueOf("10"));
```

## 3. 기본형(primitive) vs 객체형(reference)

<br>

### 📦 기본형 — 값 자체를 저장

**종류:** `int` `long` `double` `float` `char` `boolean` `byte` `short`

```java
int a = 10;
// a → 10  (값이 직접 들어있음)
```

| 특징 | 내용 |
|------|------|
| 저장 방식 | 값 자체 |
| 속도 | ⚡ 빠름 |
| null | ❌ 불가 |
| 메소드 | ❌ 없음 |

<br>

### 🗃️ 객체형 — 주소(참조)를 저장

**종류:** `String` `Integer` `ArrayList` `Stack` 등

```java
Integer a = 10;
// a → [ 10이 들어있는 객체의 주소 ]
```

| 특징 | 내용 |
|------|------|
| 저장 방식 | 주소 (참조) |
| 속도 | 상대적으로 느림 |
| null | ✅ 가능 |
| 메소드 | ✅ 있음 |

<br>

### ❓ 래퍼 클래스가 필요한 이유

> 컬렉션은 **객체만** 저장 가능하기 때문에 `int → Integer` 변환이 필요하다

```java
ArrayList<int>     list; // ❌ 컴파일 에러
ArrayList<Integer> list; // ✅ 가능
```

<br>

### 🔄 오토박싱 / 언박싱

> 자바가 자동으로 기본형 ↔ 객체형을 변환해준다

```java
Integer a = 10;  // 오토박싱  : int → Integer
int     b = a;   // 언박싱    : Integer → int
```

## 4. StringBuilder

> 문자열을 **빠르게 조작**할 때 사용 — `String` 연산보다 훨씬 효율적

```java
StringBuilder sb = new StringBuilder();
```

<br>

### 🔧 주요 메소드

| 메소드 | 역할 | 예시 |
|--------|------|------|
| `append(val)` | 뒤에 이어붙이기 | `"A"` + `123` → `"A123"` |
| `insert(idx, val)` | 중간에 삽입 | `"A123"` → `"AX123"` |
| `delete(start, end)` | 범위 삭제 (end 미포함) | index 1~2 삭제 |
| `deleteCharAt(idx)` | 특정 문자 하나 삭제 | index 0 삭제 |
| `reverse()` | 문자열 뒤집기 | `"abc"` → `"cba"` |
| `toString()` | String으로 변환 | `sb.toString()` |

<br>

### 💻 전체 흐름 예시

```java
StringBuilder sb = new StringBuilder();

sb.append("A");       // "A"
sb.append(123);       // "A123"
sb.insert(1, "X");    // "AX123"
sb.delete(1, 3);      // "A23"
sb.deleteCharAt(0);   // "23"
sb.reverse();         // "32"

String result = sb.toString(); // "32"
```

## 🔥 핵심 요약

| 개념 | 핵심 한 줄 |
|------|-----------|
| **Stack** | LIFO — 나중에 들어온 게 먼저 나온다 |
| **`parseInt()`** | `String → int` (기본형, 계산용) |
| **`valueOf()`** | `String → Integer` (객체, 컬렉션용) |
| **기본형** | 값 자체 저장 · 빠름 · null 불가 |
| **객체형** | 주소 저장 · 유연함 · null 가능 |
| **StringBuilder** | 문자열 조작 특화 클래스 |
